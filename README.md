# Megaminx Star Explorer

Interactive 151-layer Megaminx (342,012 facelets). Scramble it and every face settles into the same five-pointed star.

Live: https://mochacortado.github.io/megaminx/

- Solid view: drag to orbit, click a face to turn it (shift-click turns it back)
- Unfolded view: all 12 faces laid flat
- Orders 3 (Megaminx) through 151
- Music: "Stained-Glass Lullaby" loops quietly after the first click, tap or key press; the speaker button mutes it

Static `index.html` plus `music.mp3`; three.js r128 loads from a CDN.
